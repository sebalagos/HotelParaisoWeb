# Hotel Paraíso (Next.js + React + Bootstrap)

    npm install
    npm run api        # API simulada (json-server) en http://localhost:3001
    npm run dev        # sitio en http://localhost:3000
    npm test           # pruebas Jasmine + Karma (requiere Google Chrome)
    npm run test:cov   # pruebas con reporte de cobertura (carpeta coverage/)
